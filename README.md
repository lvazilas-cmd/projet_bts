# TP : application CRUD PHP / MySQL avec Docker Compose

Dépôt de démarrage du TP. L'environnement Docker est fourni ; l'application PHP est à construire.

👉 **Suivez l'énoncé pas à pas : [TP-PAS-A-PAS.md](TP-PAS-A-PAS.md)**

Pour commencer : **Code** → **Codespaces** → **Create codespace on main**, puis dans le terminal :

```bash
docker compose up -d --build
```
